# Of Dragons Deep

Web app that tracks the fish you've caught in Final Fantasy XIV, to help with the big fishing achievements: the Fish Guide and spearfishing log, catch-window timers, Fisher achievements, a planned route through every uncaught fish, and a shareable progress card. Live at **https://ofdragonsdeep.jadedzilla.com/** (GitHub Pages).

Built with **React + Vite** (plain JavaScript with JSX), deployed as static files.

## Commands

- `npm install` once (Playwright's Chromium for the end-to-end tests and icon scripts: `npx playwright install chromium`, unless it's already installed)
- `npm run dev`: dev server at http://localhost:5173
- `npm run build`: production build into `dist/`; `npm run preview` serves it
- `npm test`: unit and component tests (Vitest)
- `npm run lint`: ESLint with React's hooks rules (keep it clean; a disabled rule says why after `--`)
- `npm run test:e2e`: end-to-end tests in Chromium (Playwright), against a production build with the network mocked
- `npm run fetch:fish` / `fetch:icons` / `fetch:baits`: refresh the bundled data in `src/data/` and `src/assets/icons/` (need network access to v2.xivapi.com and raw.githubusercontent.com; behind a proxy on Node ≥ 22.21 run with `NODE_USE_ENV_PROXY=1`)
- `npm run fixtures`: re-record the network fixtures the tests use (same network needs); do it when the game data or the app's requests change
- `npm run app-icons`: regenerate the home-screen icons in `public/` from the clean dragon

**Deploy:** `.github/workflows/pages.yml` runs `npm ci`, `npm run lint`, `npm test` and `npm run build` on every push to `main` and publishes `dist/` to GitHub Pages (custom domain set in the repo's Settings → Pages; DNS: CNAME `ofdragonsdeep` → `jadedzilla.github.io`). Vite's `base` is `./`, so every URL stays relative and the build also works from a sub-path.

`lib/` has no React (the scripts and unit tests use it directly). Pages own their own state; app-wide state lives in the context from `App.jsx`, saved to localStorage (`lib/storage.js` lists every key). Pages are mounted the first time they're opened and stay mounted (hidden) so their data loads once. Pages that tick every second (Timers, Log Route) pass rows only the text that changes, so unchanged rows don't re-render. Data files are imported, so Vite hashes their names (no stale caches after a deploy); `fish.json` and `baits.json` load only when needed.

## Data

- **Fish Guide (live):** XIVAPI v2 `FishParameter` rows with `IsInLog`, fetched on every load as 4 parallel 500-row pages plus more while they still hold guide rows. Fields: `Item.Name/Icon/IsCollectable/Rarity`, `GatheringItemLevel`, `FishingRecordType.Addon.Text` (water), `FishingSpot.TerritoryType.PlaceNameRegion/PlaceName`, `Unknown1` (sort key). Every request pins the schema revision (`XIVAPI_SCHEMA`). Ask for linked rows as `Field@as(raw)` when only the id is needed.
- **Spearfishing:** `SpearfishingItem` rows with `IsInLog` (sort key `Unknown2`); size class in the water column; region/zone from `SpearfishingNotebook.TerritoryType`; expansion = `Unknown2` / 1000 − 2.
- **Aquarium:** `AquariumFish` (`Item@as(raw)`): `{ itemId: [size 1–4, water] }`. Optional.
- **Order:** the game's log order (sort key, then row), identical to the FFXIV Fish Tracker's. Never sort; filters keep it.
- **Rules:** expansion = level band (≤50 ARR … >90 DT), raised to the region's expansion when later; category = expansion except "The High Seas" → Ocean Fishing; big fish = `Rarity >= 2`; ocean fish have level 1 (don't show it).
- **Fallback:** if XIVAPI fails or takes over 15 s, use `src/data/fish.json`; the footer says so in amber. The footer shows the game patch (`/api/version`).
- **Teamcraft** (`fishing-sources.json`, `spearfishing-sources.json`, `fishing-spots.json`, staging branch, CORS `*`): bait and mooch chains (followed back to the real bait; several baits at a spot are alternatives), hookset (1 Powerful, 2 Precision), tug (0 Medium !!, 1 Heavy !!!, 2 Light !; 0/−1 unknown), catch windows (`spawn`, `duration`, `weathers`, `weathersFrom`; end hour snapped to the ET minute; ocean entries skipped).
- **Bait sources:** `src/data/baits.json` (vendors with zone, X/Y and price incl. currencies; crafting job + level), built from Teamcraft + XIVAPI by `npm run fetch:baits`; seasonal vendors left out.
- **Canvas size:** only in the item description's "[Suitable for printing on … canvases.]" note.
- **Icons:** packed sprite sheets (80×80, 10×10 per sheet, WebP) in `src/assets/icons/`, `src/data/icons.json` maps game icon id → index; Vite gives each sheet a hashed name. Missing icons fall back to XIVAPI's asset URL, then a placeholder. Icons fade in when their sheet loads; neighbouring pages' sheets are prefetched, the rest load in the background (not with Save-Data).

## Features

### Fish Guide (default page)
- Paged **10×10 grid**, 100 fish per page, in log order. **Fishing / Spearfishing** tabs hang from the bottom of the sheet; the choice is remembered (`odd-tab`); switching resets to page 1, keeps search and filters, and shows per-list counts.
- Toolbar: page numbers top-left with a fixed number of slots so ‹ › never move (7 on desktop, 5 at ≤ 520 px, 3 at ≤ 350 px), then search (a round icon until focused or filled), then Edit, Import, Filter at the right (icon-only; the label slides out on mouse hover). Phones: one row; an open search drops to its own row.
- **Filter:** status, category (only the list's own), big fish only, collectables only; a count badge when active.
- **Edit mode** (off on every load): click a fish to toggle caught; **Mark all caught / uncaught** for the current tab after a confirmation (Cancel focused; "Unmark all" red). Edit off: clicking a fish opens the **fish view**; mouse hover shows a tooltip.
- **Fish view:** icon, name, tags, location, water/size, level, expansion, best bait (per spot group, bait chips open the **bait view**), hookset, tug, aquarium, canvas, status, item id and the in-game description (fetched once, cached).
- **Bait view:** where to buy (6 shown, "N more vendors"; gil first, cheapest first, cities before housing) and craft a bait.

### Import (Fish Guide and Achievements)
- One dialog for the plugin's v2 export: `{"source":"OfDragonsDeep","version":2,"fish":[ids],"achievements":[{"id","complete","current","max"}]}`. Older formats and plain id lists get an "update the plugin" message.
- **Replace** (default) makes fish and achievements match the export, asking with a second click before it unmarks anything; **Add** only adds.
- **Link:** `?import=2.<base64url of raw-DEFLATE'd LEB128 varints>` (fish count + sorted id deltas, then achievement count + id delta + status 0/1/2 [+ current + max]) opens the dialog filled in; never imports by itself; the parameter is removed from the address bar.
- Then the **reveal** if new fish were caught, then a notice at the bottom (5 s, 9 s if anything was skipped).
- **Reveal:** a bobber is cast on a rope-physics line, a fish's blurry shadow rises and strikes twice (the bite mark shows the best catch: !!! big fish, !! collectable, ! otherwise), the bobber is yanked in as rays burst out and the screen floods white; the white dissolves as soon as it covers the screen while white bubbles rise through it; then up to 10 paper cards flip one after another (each starts as the one before is half over) with their kind's mark and a thin border (gold big fish, blue collectables, silver the rest); more fish show as small icons "+N more". A tap skips to the end. Then only **Close** closes it. With a mouse each card tilts toward the pointer with a foil shine; tapping a card grows it into the middle and turns it over to its details (**More details** opens the fish view); a tap beside it or Esc puts it back. The pointer cursor shows only over things that can be clicked. `prefers-reduced-motion` shows the end at once. Timing constants live in the reveal's module.

### Fish Timers (`#timers`)
- Every timed fish (443 today) with its current or next window: up-now first (soonest end), then upcoming (soonest start); countdowns tick every second and the list re-sorts as windows open and close. Filters: hide caught (on by default), big fish only, search. Click opens the fish view.
- **Weather** odds from XIVAPI (`TerritoryType.WeatherRate`); forecast with the game's formula (periods of 8 Eorzea hours = 1400 s; 1 ET hour = 175 s). `nextWindow(fish, from)` walks weather periods (previous + current must match), intersects the fish's hours (may wrap midnight), merges across periods, looks ≈ 39 days ahead. Teamcraft is credited on the page.

### Achievements (`#achievements`)
- All Fisher achievements (XIVAPI `AchievementCategory=34`, 133 today) in collapsible sections (all collapsed at first; open ones remembered): Fish log, Big fish, Ocean Fishing, Fishing milestones, Other. Summary: obtained count and points; "Hide obtained".
- Worked out from caught fish where possible: counter 202 (unique fish), big-fish counters 267 / 826 / 1000 / 1145, Denizens/Specters (every fish at an ocean stop, shown as icons). Meta achievements are **groups** with their parts nested (open by default, closed ones remembered). Everything else has an "Obtained" checkbox. Imported in-game progress shows as "312 / 500 in game"; a "Last imported …" line under the summary.

### Log Route (`#route`)
- Plans the order to catch every uncaught Fish Guide fish from now (`planLogRoute()`, pure): spot stops by greedy set cover (grouped by zone), timed fish by simulating the clock (rare ones as soon as open, frequent ones after a stop in their zone), ocean fishing last (one step per voyage stop with port, time of day, example route and weather), then fish with no window soon and fish without data.
- Each fish: bait → mooch chain with hookset and tug, intuition, snagging, lures, minimum Gathering. Step 1 says **Next**; later timed steps show an estimated local time; timed steps show ET hours, weather and a live countdown (turns green when up; removed when missed, with a "re-plan" note).
- Header: summary tiles, notes, **Include timed fish** (off by default, remembered), **Re-plan**, **GatherBuddy** (desktop only: copies the whole land route as a GatherBuddy Reborn auto-gather list: base64 of gzip(byte 6 + JSON), 1 of each fish pinned to its spot, imported disabled, "Copied!" feedback). 15 steps at a time; a ✓ marks a fish caught without re-planning.

### Share (`#share`)
- A 1200×675 PNG of your progress drawn on a canvas: a torn-paper sheet (seeded tear) with the paper texture in the current mode's colours, on a fully transparent background. Fish Guide / spearfishing / big fish / ocean counts and % per expansion; achievements obtained and points, **Recently obtained** and **Almost there** (3 each, XIVAPI icons). Optional character name and the date. **Download PNG**, **Share…** (where the Web Share API takes files), **Copy image**.
- "Recently obtained" uses the first time the app saw each achievement obtained (`odd-achievements-seen-v1`).

### Everywhere
- **Loading placeholders** (shimmering shapes) wherever something loads, including a page opened directly by its hash; no shimmer with reduced motion.
- **Credit line** at the bottom of every page: "created with 🐟 by jadedzilla".
- **Home-screen app:** standalone manifest (`start_url`/`scope` `./`, theme `#141414`, icons 192/512 + maskable), iOS meta tags with a translucent status bar (safe-area padding); no service worker.

## Design

After the Carrd **A Fisher's Guide to Eorzea**:
- **Light and dark mode** (`html[data-theme]`), set before first paint from the saved choice (`odd-theme`) or the device setting; the sun/moon button in the title bar switches it. Light: greige page, stone cards, charcoal ink, slate-grey secondary text. Dark: charcoal page, warm dark-grey cards, paper ink.
- **Paper texture:** `src/assets/bg.jpg`, used as it is (never edited or filtered), blended with `soft-light` over the page, the reveal cards and the share card.
- **Layout:** no window frame; title "Of Dragons Deep" in large Neuton (text only, no logo; the Nepto Dragon is the favicon); each page's content on a raised **sheet**.
- **Fonts:** Neuton (titles, headings), Montserrat (names, numbers, navigation), Rethink Sans (text).
- **Controls:** current page and page number are a filled pill; Edit / Import / Filter / theme are round filled icon buttons; primary buttons filled; other buttons outlined in ink and fill on hover; danger is red. Edit on is gold.
- **Fish kinds:** big fish gold, collectables blue, caught / up now green, other reveal cards silver.
- **Tokens:** colours, fonts and radii are CSS variables in `src/styles/tokens.css` (per mode); use them, not raw values. One rule per selector.
- **Consistency:** every fish or game icon frame rounds at `--r-icon` with its art enlarged by `--icon-zoom` (hides the art's darker rim); every floating panel (dialogs, filter panel, tooltip, notice) has the sheets' hairline edge (`--sheet-line`); the pointer cursor shows only on things that can be clicked.
